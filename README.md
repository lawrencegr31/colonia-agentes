# Colonia de Agentes

Vista en vivo, estilo simulador de colonias, de las sesiones de Claude Code de una computadora.
Cada sesión es un colono y cada carpeta de trabajo es una sala.

Solo lee los registros locales de Claude Code (`~/.claude/projects`). No envía datos a ningún lado
y la página solo se sirve en `127.0.0.1`.

Uso en Windows: doble clic en `Abrir Colonia.bat`. Al abrir busca la última versión de este
repositorio y la descarga sola.
